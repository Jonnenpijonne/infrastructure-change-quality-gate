# Evidence directory

This directory contains **curated historical demonstration evidence** committed to the repository.

It is not the output location for the current GitHub Actions run.

## Current-run evidence

Current audit evidence is generated by:

```bash
bash scripts/generate-audit-report.sh
```

The generated report is written under `reports/` (ignored by Git) and the dedicated **Gatehouse Audit Evidence Report** GitHub Actions workflow uploads that generated directory as a run artifact.

## Historical reports

Files under `evidence/compliance-reports/` are retained only as sanitized portfolio/history examples. They must not be uploaded by another workflow and represented as evidence from the current run.

Some historical reports were produced when the project used ISO/IEC 27001:2013 Annex A identifiers such as:

- A.12.1.2 — Change management
- A.14.2.2 — System change control procedures
- A.12.4.1 — Event logging

The current documentation uses ISO/IEC 27001:2022 reference controls, primarily A.8.32 (Change management), A.8.15 (Logging) and A.5.37 (Documented operating procedures).

Historical evidence is intentionally not rewritten to look as though it was generated by a newer policy version.

## Data handling

Committed evidence must be synthetic and non-sensitive. Do not commit production credentials, customer data, real access assignments, confidential change records or unredacted operational logs.
